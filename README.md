# PlatePilot

PlatePilot is a modern AI meal planner app concept built with Next.js and Tailwind CSS.

The project helps users plan meals for the week, organize recipes, review nutrition targets and generate a clean shopping list with ingredient quantities.

## About the Project

PlatePilot is designed as a fictional AI-powered meal planning application.

The goal of the project is to demonstrate modern frontend development skills, app-style UI design, responsive layouts and clean component structure.

The app concept includes:

- AI meal planning landing page
- Warm food-tech visual design
- Custom navigation
- Weekly meal plan preview
- Planner form
- Nutrition summary
- Benefits section
- How it works section
- Shopping list with ingredient quantities
- Mobile-friendly layout
- Vercel deployment

Key Features
AI Meal Planner Concept

PlatePilot is built around the idea of generating weekly meal plans based on user goals, food preferences, budget and daily meal structure.

Weekly Meal Plan UI

The project includes a structured weekly plan layout with meals grouped by day, calories and protein information.

Nutrition Summary

A dedicated nutrition section displays average calories, protein, carbs and fat targets for the planned meals.

Shopping List

The shopping list organizes ingredients with quantities, making the concept feel more like a real meal planning application.

Responsive Design

The interface is optimized for desktop and mobile screens with adjusted spacing, cards and layout behavior.
